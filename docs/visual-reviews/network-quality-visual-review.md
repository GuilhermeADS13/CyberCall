# Revisão visual da qualidade de conexão

As capturas em 1280×720 e 390×844 mostram o shell CyberCall sem regressões de layout, contraste ou navegação. O indicador individual de conexão fica encapsulado no overlay da sala e não altera o modo visitante.

Com a chamada ativa, cada tile exibe quatro barras com cor semântica: ciano para conexão boa, âmbar para instável, vermelho para baixa e cinza para indisponível. O tooltip e o aria-label informam a classificação e, quando disponível, o RTT. A telemetria da sala também resume o pior estado de rede entre os participantes.
